# MathModelingTemplate

数学建模比赛代码仓库的简易模版

## Feature

本模板仓库可以：

- 支持 Actions 自动编译 $\LaTeX$ 文档
- 提供基础的 Python 代码模板，包括简易的日志模块[^1]
- 支持 Python 代码的自动运行[^2]

[^1]: 见 [`program.utils.logger`](https://github.com/HZMath/MathModelingTemplate/blob/main/src/program/utils/logger.py) 模块
[^2]: 由 GitHub Actions 提供支持
